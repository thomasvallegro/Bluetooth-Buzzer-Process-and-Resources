# Bluetooth Buzzer | Process and Resources
Il Git in oggetto spiega e condivide il progetto "Bluetooth Buzzer", interamente ideato dal sottoscritto. Il presente documento funge da "manuale di istruzioni":  suddivide in sezioni tutto ciò che serve per riuscire a ricostruire il progetto finito.

**Introduzione: Presentazione del progetto**

L'idea abbraccia stampa 3d e microcontrollore ESP 32 con lo scopo di integrarsi perfettamente con ogni progetto che cerca un'interazione simpatica e divertente. Ciò simula a livello pratico il tasto "a" di una semplice tastiera che comunica via Bluetooth con un dispositivo esterno. 
Nativamente è stato progetatto per integrarsi con il software OBS STUDIO, attraverso una Macro inserita con il plugin "Advanced Scene Switcher", per gli amici "ASS" (non culo!). La macro attiva una scena per simulare un Photo Booth con cornice personalizzata.
